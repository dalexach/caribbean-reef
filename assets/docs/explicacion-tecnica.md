
# Explicación técnica

- `main.js` renderiza servicios desde JSON.
- `contact.js` valida el formulario.
- `services-data.js` sirve de respaldo si se abre el proyecto con doble clic.
- `services.html` contiene el detalle expandible.
- `index.html`, `about.html` y `contact.html` fueron adaptados visualmente según los mockups.
